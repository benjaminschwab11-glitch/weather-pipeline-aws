## Management Operations

### To View Schedule Status
1. AWS Console → EventBridge → Scheduler → Schedules
2. Find: weather-pipeline-schedule
3. Check State: Enabled

### To Temporarily Disable
1. EventBridge → Scheduler → Schedules
2. Select: weather-pipeline-schedule
3. Actions → Disable

### To Change Frequency
1. EventBridge → Scheduler → Schedules
2. Select: weather-pipeline-schedule
3. Actions → Edit
4. Change rate expression
5. Save changes

### To Delete Schedule
1. EventBridge → Scheduler → Schedules
2. Select: weather-pipeline-schedule
3. Actions → Delete
4. Note: Lambda function remains, just stops auto-triggering
